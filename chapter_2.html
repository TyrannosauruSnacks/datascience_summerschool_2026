2.3 Python Language Basics

Python uses “significant” whitespace. Which means that the indentation of lines matters for the execution of the code. In R for example, whitespace is arbitrary and for human viewing only.

Colons “:” denote an indented code block, and semicolons “;” separate code chunks in the same line.

Everything in Python is an object, even functions.

The pound mark “#” denotes a comment, which is a part of the script that will not be evaluated.

Functions are called with parentheses “()”, in which also the arguments can be set. The returned value of that function call can directly be assinged to a new variable with =.

Most Python objects also have further functions that are referred to as methods. These can be accessed by appending a period “.” to the object, e.g.: object.some_method.

Variables and Argument Passing

When assigning a variable to something in Python the variable is only a reference to the object. In Python, this means that assigning several variables to the same object does not copy it, but rather creates two references to the same object. For example:

# Assing a to a list of three numbers.
a = [1, 2, 3]

# Assign b to a
b = a

# Show both
a

Attributes and Methods

Objects can have both attributes and methods (functions that directly access the object data) assigned to them, wich all are accessible with appending a period to the object like: object.attribute/funcion.

Duck Typing

Instead of checking the type you can also just check whether a certain behaviour is possible for an object; this is referred to as duck typing, in the sense of “if it walks like a duck and quacks like a duck, it is a duck”.

For example, most strings and Python collection types are iterable:

def isiterable(obj):
    try:
        iter(obj)
        return True
    except TypeError: # not iterable
        return False

isiterable("a string")

isiterable([1, 2, 3])

isiterable(5)
True
True
False

Imports

Modules are any files with a .py extension containing Python code. Their code can be accessed and used with the import function.

So I’ve written a the file some_module.py with the following code:

# some_module.py
PI = 3.141359


def f(x):
    return x + 2


def g(a, b):
    return a + b

I can import the whole module, meaning all its functions are accessible in this session (they are in scope):

import some_module

result = some_module.f(5)
pi = some_module.PI

result
pi
7
3.141359

Or we can use from to import specific parts of the module:

from some_module import g, PI

result = g(5, PI)
result
8.141359

Also, with the as keyword the imports can be assinged individual variables:

import some_module as sm
from some_module import PI as pi, g as gf

# Here we call the *method* "f" of sm.
r1 = sm.f(pi)

# And here we call both `gf` and `pi` which we assigned before.
r2 = gf(6, pi)

print(r1, r2)
5.141359 9.141359

Dates and Times

The datetime module is a built-in of Python to handle the types datetime, date, and time.

datetimes have the following default format: datetime(YYYY, mm, dd, HH, MM, SS), and can be accessed with their natural language equivalents.

This package has to be imported first:

# We select single functions from the package here
from datetime import datetime, date, time

dt = datetime(2026, 7, 29, 11, 43, 46)

print(dt.day, dt.year, dt.second)
29 2026 46

We can split a datetime object into its main parts date and time with the corresponding methods.

print(dt.date(), dt.time())
2026-07-29 11:43:46

We can get “strings from time” with the strftime method with the according wildcards.

dt.strftime("%Y-%m-%d %H:%M %S\'\'")
"2026-07-29 11:43 46''"

And from “string parse time” with the strptime method:

datetime.strptime("20260729114346", "%Y%m%d%H%M%S")
datetime.datetime(2026, 7, 29, 11, 43, 46)

Control Flow

if, elif and else

The if statement checks a condition, and if that is True evaluates the code block that follows.

x = -5
if x < 0:
    print("It's negative.")
It's negative.

To iterate further, if statements can be followed by elif (else if), to check for another condition with the else statement as the result when all other checks turned out false.

x = 0

if x < 0:
    print("It's negative.")
elif x == 0:
    print("Equal to zero")
elif 0 < x < 5:
    print("Between zero and five")
else:
    print("Positive and five or larger")
Equal to zero

Compound conditions – those with and and or - are evaluated from left to right. For example, if the first statement of an or check is True then the other conditions are not checked and the following code block is evaluated directly.

for loops

for loops iterate over collection of values (vector in R) like lists or tuples. Here is how to read a for expression:

for each_value in collection:
    do_x

Take each value of that collection and do the task with that value in mind. For example, sum up all the values with the += statement:

collection = [1, 2, 3, 4, 5, 6]
total = 0

for each_value in collection:
    # if value is None:
    #     continue
    total += each_value
print(total)
21

Note that the name for each_object can be arbitrarly defined and is just there as a pointer to be referenced in the functions body. So the following expression works the same:

for i in collection:
    total += i
print(total)    
42

You can tell a loop to continue in cases that your actual function might fail. For example, the += can only handle integers and will fail when there is an empty None value, which often is the case with data in the wild:

collection = [1, 2, None, 3, None, 5]

for i in collection:
    total += i
print(total)
---------------------------------------------------------------------------

----> 4     total += i

So here you can tell your loop: if you find a None just continue:

for i in collection:
    if i is None:
        continue
    total += i
print(total)
56

break is used to end the loop at a given condition. So if we wanted to sum all the values till a zero comes up:

collection = [1, 2, 3, 7, 0, 6, 9, 1]
total_till_0 = 0

for i in collection:
    if i == 0:
        break
    total_till_0 += i
print(total_till_0)
13
